## 2026-07-25 - [Environment Variable-Based Token Configuration]
**Vulnerability:** Found a hardcoded Telegram Bot API Token inside the `carrybee_reminder_bot.py` script and documented in `README.md`. If committed to a public repository, these secrets could be exposed, leading to unauthorized control of the bot, potential spamming, or resource exhaustion.
**Learning:** Storing secrets in source files or static documentation is insecure and violates security best practices. Dynamic retrieval from the environment prevents credential leakage. However, when adding checks in Python modules, these validation checks should be scoped inside the module's `if __name__ == '__main__':` boundary so that importing files or test runners do not terminate prematurely.
**Prevention:** Always load application secrets, API keys, and configurations from environment variables (e.g. `TELEGRAM_BOT_TOKEN`) rather than hardcoding them in files. Perform startup validation inside the main entry point block to keep test/import processes functional.
