## 2026-06-29 - Hardcoded Secrets and HTML Parsing Vulnerabilities in Reminder Telegram Bot
**Vulnerability:** The Telegram reminder bot had its sensitive API token (`BOT_TOKEN`) hardcoded in both the code and `README.md` file, which could easily lead to key exposure if the codebase is made public. Additionally, user-controlled fields sent in Telegram messages were not escaped, allowing malformed HTML inputs or HTML injection to cause Telegram's HTML parser to fail, rendering the bot unable to send reminders.
**Learning:** Hardcoding credentials makes secrets management and rotation extremely difficult and risks complete exposure. Furthermore, rendering dynamic data directly into formatted Telegram HTML messages without escaping HTML entities breaks format parsing when inputs contain characters like `<`, `>`, or `&`.
**Prevention:** Secrets must always be loaded via environment variables or a secure key management system. All user-supplied dynamic fields rendered into formatted templates (like HTML or Markdown) must be fully escaped using standard libraries (such as `html.escape` in Python) before sending them to external APIs.
