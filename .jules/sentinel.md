## 2026-07-26 - [Hardcoded Telegram Bot Token & Message HTML Injection]
**Vulnerability:** Found a plaintext hardcoded Telegram bot token in both `carrybee_reminder_bot.py` and `README.md` which poses a major security risk as token leaks can compromise the entire bot channel. Additionally, dynamic ticket fields retrieved from external/untrusted sources (Google Sheets) were rendered directly into Telegram message templates with HTML parse mode enabled, allowing potential HTML/XSS injection or rendering/parsing errors.
**Learning:** Hardcoding secrets or credentials in repository files often stems from quick initial setups or lack of a clear environment variable configuration pattern. Lack of output sanitization/escaping on text strings when using structured message formats (HTML, Markdown) allows malicious input or unexpected characters to break parsers or execute unwanted code.
**Prevention:** Always retrieve authentication credentials/tokens strictly from environment variables (e.g. using `os.environ.get`) and never commit credentials or publish them in documentation. Always escape dynamic untrusted inputs using robust sanitization libraries (e.g., standard `html.escape`) before formatting them inside templates or rich text payloads.
