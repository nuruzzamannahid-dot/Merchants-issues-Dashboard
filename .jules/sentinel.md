## 2026-06-29 - Telegram Bot Token Hardcoded in Configuration and Documentation
**Vulnerability:** A highly critical hardcoded Telegram Bot Token secret was exposed in both `carrybee_reminder_bot.py` and `README.md`.
**Learning:** Hardcoding api keys or authorization tokens directly in public or shared source code repos compromises authorization controls, allowing unauthorized entities to control the bot or read/write messages. Furthermore, any environment variable validations in imported/runnable Python modules must be guarded inside the `if __name__ == '__main__':` execution context to allow test runners or other importing scripts to load the module smoothly without crashing on startup.
**Prevention:** Always externalize application secrets such as API credentials, database tokens, and Telegram bot tokens to configuration systems or system environment variables (e.g., using `os.environ.get('TELEGRAM_BOT_TOKEN')`). Implement fail-safe dynamic checking during the script's actual entry point.
