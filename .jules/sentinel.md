## 2026-07-26 - [Stored Cross-Site Scripting (XSS) in Client-Side Dynamic Templates]
**Vulnerability:** Stored HTML/JS payloads from external sources (such as custom merchant/consignee fields, tags, and issue details) could execute arbitrary JavaScript in operator sessions because the retrieved database fields were directly interpolated into HTML template literals and parsed via `.innerHTML`.
**Learning:** Directly interpolating unescaped, user-controlled data into HTML string templates that are subsequently parsed by the browser allows the execution of arbitrary scripts in the operator's browser session. In applications where user context (like emails and names) is preserved in `localStorage`, this immediately exposes operator credentials and sensitive operation sessions to theft or unauthorized action.
**Prevention:** Always escape dynamic content using a secure HTML entity encoder/escaper before interpolating it into HTML template blocks, especially when updating the DOM with `.innerHTML`. For plain text nodes, prefer using safe properties like `.innerText` or `.textContent`.
