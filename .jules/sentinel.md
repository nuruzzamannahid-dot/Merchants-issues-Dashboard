## 2026-07-02 - [Dynamic Bot Token Loading]
**Vulnerability:** A highly critical hardcoded Telegram Bot API Token was found in the configuration block of `carrybee_reminder_bot.py` and documented in the public `README.md` file. This exposed the bot to unauthorized control, allowing attackers to hijack communications, send spam/malicious messages to CarryBee operations chats, or query system updates.
**Learning:** Hardcoding api tokens in script files or public configuration documents poses high security leak risks, especially if the code is pushed to public repositories. Environment variables should always be used as the primary mechanism for storing sensitive configuration values.
**Prevention:** Always load sensitive API tokens, passwords, and private keys dynamically from the environment (e.g. `os.environ.get('TELEGRAM_BOT_TOKEN')`). Implement early validation checks during application startup to fail fast and securely with exit codes if required environment variables are absent. Ensure validation is wrapped within the module main entry boundary (`if __name__ == '__main__':`) to prevent test suites or importers from failing prematurely during non-execution imports.
