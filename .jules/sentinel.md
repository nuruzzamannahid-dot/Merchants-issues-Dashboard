## 2026-02-27 - [Hardcoded Telegram Bot Token]
**Vulnerability:** A hardcoded active Telegram Bot Token (`8851597317:AAGAjKaTjxp8oJga0reO64se9VhEBf2gYUc`) was discovered in both the codebase (`carrybee_reminder_bot.py`) and documentation (`README.md`). This allows anyone with access to the repository to control the bot, impersonate it, send unsolicited spam/phishing messages to users, or intercept potential updates if they have access to the chat IDs.
**Learning:** Hardcoding credentials makes development faster but introduces severe security risks when code is pushed to any shared or public repository. Environment variables are the industry standard for passing runtime configuration secrets securely.
**Prevention:** Never commit API keys or secret tokens directly to the repository. Load secrets from environment variables (e.g., via `os.environ` in Python) and document how users can configure these environment variables in their local/production environment safely. Use tools like `git-secrets` or pre-commit hooks to detect secrets before they are committed.
