## 2026-07-24 - Intercepting API Delays to Validate Micro-UX State Transitions
**Learning:** In purely static, client-side single-page applications with backend-driven forms, missing loading indicators and button disabling during network requests creates a high probability of double-submissions. Since we lack local state-management libraries (like Redux or React's useState), vanilla DOM manipulation combined with a structured `try-finally` block is the most robust way to ensure buttons are properly restored.
**Action:** When validating micro-UX state transitions in end-to-end environments, use browser request interception (`page.route` in Playwright) to introduce a deliberate delay. This guarantees the screenshot captures the intermediate state ("Submitting...") rather than transitioning too quickly to the success state.
